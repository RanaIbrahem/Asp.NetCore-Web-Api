🔹 Description

This project is a full backend API for an e-commerce platform developed using ASP.NET Core Web API.
It manages users, products, and orders with secure authentication and a relational database (SQL Server).


🛠 Technologies

Backend: ASP.NET Core Web API, C#
Database: SQL Server
Other: Entity Framework Core, RESTful API principles, Postman


⚙️ Features

User registration & authentication
Product CRUD operations
Order management and checkout
Secure endpoints with role-based access
